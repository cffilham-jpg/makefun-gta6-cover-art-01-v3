Build a photo collage styled like a Vice City cover. Start with one of six moods, add your own photos, drag each panel to reframe it, and set the headline and film grade. Export PNGs in 1920 × 1080, 1080 × 1350, or 1080 × 1080. All editing and export happen in the browser using local assets.

Run `node serve.ts` and open [localhost:8080](http://localhost:8080) in desktop Chrome. No build step or packages are required. Use `MAKEFUN_OUTPUT_DIR=out node main.ts` to generate the entry dossier.

The eight layouts are Hero, Poster 2x2, Triptych, Quad, Strip, Duo, Diagonal Split, and Film Strip. The eight grades are Sunset, Electric, Gold, Vice, Noir, Heat, Miami Pink, and Teal Night. Presets are Sunset Heist, Neon Nights, Vice Drive, Beach Noir, Neon Getaway, and Coastal Cruise.

Anton and Archivo Black ship under the SIL Open Font License. Each matching license is included beside its font in `app/fonts/`. [Anton](https://github.com/google/fonts/tree/main/ofl/anton) · [Archivo Black](https://github.com/google/fonts/tree/main/ofl/archivoblack)
